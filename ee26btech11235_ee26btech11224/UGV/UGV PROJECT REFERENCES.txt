4. USE OF ARTIFICIAL INTELLIGENCE
==================================================

[7] OpenAI, "ChatGPT."
https://chatgpt.com/

ChatGPT was used as an AI-assisted tool during the development of the UGV project.

The assistance included:

- Understanding ESP32 microcontroller concepts and PWM-based motor control.
- Planning the implementation of independent motor control.
- Understanding Bluetooth communication and smartphone-based control using Dabble.
- Developing and improving Arduino/ESP32 code.
- Discussing smooth acceleration and deceleration techniques.
- Troubleshooting hardware and software issues.
- Understanding Bluetooth disconnection handling and fail-safe stopping.
- Improving code readability, organisation, and documentation.
- Preparing and formatting the project progress log using LaTeX.

AI-generated suggestions were treated as guidance and were reviewed against technical documentation and practical testing wherever applicable.

The hardware implementation, physical assembly, testing, observations, and final verification of the project were carried out by the project author.
